## File Catalog

### 1. Source Code (`rtl/`)

| File | Description | Checklist item |
|------|-------------|----------------|
| `rtl/top.sv` | Integrated top module: AXI4-Lite write pipeline, weight staging, result capture, DONE flag. **Differs from M3** in two places: (1) project comment updated "Systolic Array" → "Parallel PE Array"; (2) `cnn_interface` instantiation adds `.result_in(32'b0)` to tie off the previously-floating input port. Functionally identical to the synthesized M3 version. | §2 Final RTL |
| `rtl/interface.sv` | AXI4-Lite slave (`axi4lite_slave`) + wrapper (`cnn_interface`). Unchanged from `project/m3/rtl/interface.sv`. | §2 Final RTL |
| `rtl/compute_core.sv` | Weight-stationary parallel PE array core: 4 conv_pe instances, weight memory FFs, result packing. Unchanged from `project/m2/rtl/compute_core.sv`. | §2 Final RTL |
| `rtl/conv_pe.sv` | Single INT8 MAC processing element: 8×8 signed multiply, 32-bit accumulator, KERNEL_SIZE tap counter. Unchanged from `project/m2/rtl/conv_pe.sv`. | §2 Final RTL |

**Diff from M3 RTL:** `top.sv` has two cosmetic changes vs M3 (comment + `result_in` tie-off). These do not affect the synthesized netlist — the OpenLane 2 run in `synth/openlane_run.log` was performed on the M3 version; the M4 changes are functionally equivalent. `interface.sv`, `compute_core.sv`, and `conv_pe.sv` are byte-identical to their M3/M2 originals.

### 2. Testbench (`tb/`)

| File | Description | Checklist item |
|------|-------------|----------------|
| `tb/tb_top.sv` | Self-contained AXI4-Lite testbench. **Substantially revised from M3:** loads weights once, then runs **3 back-to-back patch invocations** with `$time` markers and a printed TIMING SUMMARY (153 lines vs M3's 25). Diffs from M3: (1) `$dumpfile` changed to `final_waveform.vcd`; (2) single test sequence replaced with a 3-iteration `for` loop; (3) `t_measure_start`/`t_measure_end` timing variables added; (4) TIMING SUMMARY block prints elapsed ns, total cycles, and cycles/patch. PASS/FAIL contract unchanged. | §2 Final testbench |

**How to run** (Icarus Verilog):
```sh
iverilog -g2012 -o sim_out tb/tb_top.sv rtl/top.sv rtl/interface.sv rtl/compute_core.sv rtl/conv_pe.sv
vvp sim_out
```
