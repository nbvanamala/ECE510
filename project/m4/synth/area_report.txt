--- Dominant Area Contributors ---

By module (estimated from Yosys cell counts × sky130 avg cell area):

  Module          Cells   Est. Fraction   Notes
  conv_pe x4      ~3,052  ~52%            4 INT8×INT8 MAC units + 32b accumulators
  top (glue)        ~562  ~12%            AXI write pipeline, result regs, DONE flag
  axi4lite_slave    ~464  ~10%            AXI4-Lite FSM, register file
  compute_core      ~233   ~5%            Weight memory FFs, valid pipeline
  Other (buffers, clock tree, routing cells added by OpenROAD): ~21%

The conv_pe array is the dominant area consumer, as expected for a
compute-intensive MAC design. The 32-bit accumulator register per PE
and the INT8 signed multiplier logic account for the majority of the
conv_pe cell count.

  Reduction ratio                           :  ~2.4× fewer cells after technology mapping

   collapse into single sky130 compound gates during synthesis optimization.)
